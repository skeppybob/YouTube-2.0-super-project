# Flying Eagle

A dark, airsoft-focused video library for game days, fieldcraft, loadouts, gear, and tuning.

## Product direction

- Original YouTube-style browsing and playback experience
- Airsoft-focused content and categories
- No ads, paid tiers, or monetization
- Built as a pnpm workspace with a React + Vite frontend

## Run

`pnpm install`

`pnpm --filter @workspace/flying-eagle run dev`
